# Active Directoryの教科書 練習用ファイル

書籍『Active Directoryの教科書 Windows Server 2025対応 構築・ユーザー管理・グループポリシー』（早瀬 透）の練習用ファイルです。

本では、架空の会社「みどり文具株式会社」の Active Directory を、Azure の上に一から作ります。
このページには、本の中で打つ長いコマンドと、第12章でまとめて登録する社員の一覧の表を置いています。
長いコマンドを手で打つと、打ち間違いで動かないことがあります。ここからコピーして貼り付けてください。

## 使い方

ほとんどの章では、ファイルをダウンロードする必要はありません。ブラウザーでファイルを開き、中身をコピーして使います。

1. 下の表の、使う章のファイル名を押します。ファイルの中身が表示されます
2. 中身の右上にある、四角が2つ重なったボタン（Copy raw file）を押すと、全部がコピーされます。一部だけ使うときは、使う行をマウスで選んでコピーします
3. コピーしたものを、本の指示どおりに貼り付けます
   - Cloud Shell（第4章）：ウィンドウを一度押してから Ctrl＋V（Mac は ⌘＋V）
   - DC01・PC01 の PowerShell（第4・5・12・13章）：PowerShell のウィンドウの中で右クリック（Mac は2本指でクリック）

手元のパソコンでコピーしたものは、リモートデスクトップのウィンドウの中にもそのまま貼り付けられます。

## 第12章だけは DC01 にダウンロードします

第12章では、社員の一覧の表とスクリプトを、DC01 の C:\work にダウンロードして使います。
やり方は本の第12章の section 02 に書いてあります。commands.txt の section 02 の5行を、DC01 の PowerShell に1行ずつ貼り付けると、このページのファイルがまとめて C:\work に用意されます。

うまくダウンロードできないときは、DC01 の Microsoft Edge でこのページを開きます。上の緑の［Code］→［Download ZIP］でダウンロードし、エクスプローラーで広げて、ch12 フォルダーの中の5つのファイルを C:\work にコピーします。

## 知っておくこと

- 社員の名前・会社名（みどり文具株式会社）・ドメイン名（corp.example.com）は、すべて架空です
- employees.csv の最後の1行は、わざと部署を「総務」と書き間違えてあります。第12章で、登録する前の試しの実行（-WhatIf）で見つけて直す練習に使います
- スクリプト（.ps1）は「UTF-8（BOM 付き）」で保存してあります。自分で書き換えて保存するときも、同じ文字コードで保存してください。BOM が無いと、Windows PowerShell 5.1 が日本語を読み違えて動きません
